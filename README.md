>一个神话奇幻的《我的世界》1.20.1（Forge）模组：提取元素能量，打破上古的封印，并夺取被禁的神话遗物。
- **Minecraft**：1.20.1
- **加载器**：Forge 47.x（开发环境 47.4.3）
- **Java**：17
- **mod id**：`mythic_relic`
- **可选依赖**：JEI 15+（只用来查看「元素提取器」的配方，不装也照常运行）
- **许可证**：MIT

## 这是什么

神话之遗往里加的东西不多，但每一件都咬在一条玩法线上：**提取**（把方块与材料拆成能量）、**封印**（走完仪式、进封印之地、面对尼德霍格）、**诅咒**（从石头里拔出一把认得人的剑）、**越界**（撕开空间抄近路）。

全书内容都写在一本开局就发给你的《神话之书》里，游戏内可查。

## 四条玩法线

### 一、主线 · 混沌

元素提取器（1 个输入 + 并排 3 个输出，配方数据驱动）
→ 混沌能量痕迹 / 碎片 / 结晶
→ 混沌祭坛 + 封印符文，走完封印仪式（龙语对白）
→ 用**混沌之钥**右键末地折跃门，进入**封印之地**维度
→ 尼德霍格
→ **尼德霍格之印**。

戴上尼德霍格之印之后会按「混沌进度」分阶段解锁：龙翼滑翔、悬停、混沌领域、暗影龙刃，另有贪欲 / 暴食 / 起源三系被动。进度溢出后持续转化为生命上限。

### 二、死亡线

死亡能量痕迹 / 碎片 / 结晶 → **死亡之心**（9 死亡能量结晶 + 下界之星）。

佩戴后生命归零不会立刻死亡，血量可以掉到负数，给你 5 分钟爬回正数；超时则真正死亡。冷却 300 秒，界面上有负数血量的 HUD。

### 三、赫格尼线

世界生成会刷出**诅咒祭坛**（可用 `/locate` 找）。对着祭坛上的剑点满 100 下才能把它拔出来——但祭坛周围挂着凋零，二十息足以致命。

拔出**赫格尼之剑**的人会获得「赫格尼的诅咒」：命中时诅咒目标，使其无法回血、不死图腾也无法触发；同时你本人获得**永久凋零免疫**。

### 四、裂隙线

**破界之羽**：手持右键瞬息移至视线所指之处（最远 1000 格）；潜行右键打开坐标界面，可精准抵达范围内任意位置。

## 材料与合成链

空间、棱镜、剧毒三套新材料，都遵循同一条 **9 : 1** 的合成链：

| 类别 | 痕迹（入口材料） | 碎片（9 痕迹） | 结晶（9 碎片） | 成品 |
| --- | --- | --- | --- | --- |
| 混沌 | 混沌能量痕迹 | 混沌能量碎片 | 混沌能量结晶 | — |
| 死亡 | 死亡能量痕迹 | 死亡能量碎片 | 死亡能量结晶 | 死亡之心 |
| 空间 | 空间能量痕迹 | 空间能量碎片 | 空间能量结晶 | 神棱偏转镜 |
| 棱镜 | 棱镜能量痕迹 | 棱镜能量碎片 | 棱镜能量结晶 | 神棱偏转镜 |
| 剧毒 | 剧毒能量痕迹 | 剧毒能量碎片 | 剧毒能量结晶 | 百毒不侵之戒 |

- **神棱偏转镜**：5 棱镜碎片 + 4 空间碎片。手持右键开启 60 秒「神棱偏转」——有源伤害全额反弹给攻击者，无源伤害（摔落 / 火 / 虚空）直接免疫；放进饰品栏后，血量低于阈值会自动开启。
- **百毒不侵之戒**：8 片剧毒碎片围成一圈。戴上后所有负面效果都施加不上来，身上已有的也会慢慢化掉。
- **《神话之书》**：书 + 黑曜石（无序配方）可再造一册。

## 饰品栏与快捷键

- **V**：打开／关闭 6 格饰品栏。
- **R**：释放「混沌领域」（需佩戴尼德霍格之印）。
- 饰品栏里的装备支持**手持右键装备**、以及打开饰品栏后 **Shift + 右键**快速放入。
- 饰品栏**只接受本模组实现 `AccessoryItem` 接口的物品**，其它东西放不进去。

## 游戏内手册

开局自动发放《神话之书》，右键翻开。目录分「序 / 卷一 · 本源与材料 / 卷二 · 封印与神龙 / 卷三 · 异宝与禁术 / 跋」五节，**目录条目可直接点击跳页**（悬停会变金色并压一条下划线），正文页底部有「&lt; 目录」一键回到目录首页。

全书正文走语言文件（`book.mythic_relic.page.N`），中英文都随客户端语言切换。

## 自己构建

需要 **JDK 17**。

```bash
./gradlew build          # Windows: gradlew.bat build
```

产物位于 `build/libs/mythic_relic-1.0.0.jar`。

- JEI 的 API 以 `compileOnly` 方式引用仓库内 `libs/` 下的两个 jar，仅在编译期可见，**不会打进最终 jar**，玩家装没装 JEI 都能正常开游戏。
- `libs/` 与 Gradle Wrapper 都随仓库提供，因此也可以离线构建：`./gradlew build --offline`。

## 设计约定

- 混沌等级、死亡之心冷却这类**属于玩家**的数据一律存在玩家 capability 里，不写物品 NBT——多人游戏下不会互串。
- 客户端的数据副本在玩家登出（`ClientPlayerNetworkEvent.LoggingOut`）时统一 `reset()`，换存档／换服务器不留残渣。
- 程序化生成的材质统一用 Python + Pillow 画：先出单通道蒙版定轮廓，再统一上色，方便做外发光与衰减。
